# Prime Video Cookie Checker

Bot untuk cek validitas cookie Prime Video secara massal.

## Install
```bash
pip install -r requirements.txt
```

## Cara Pakai
1. Taruh file cookie (.txt) di folder `cookies/`
2. Jalankan:
```bash
python checker.py
```
3. Hasil valid akan disimpan di `results/valid.txt`

## Format Cookie
Satu file .txt per akun, isi cookie string dari browser.
